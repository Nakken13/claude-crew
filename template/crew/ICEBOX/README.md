Ideas/tasks **deliberately parked** — distinct from `TODO/` (which means
"not started yet but planned"). A task in ICEBOX is **not** in the active
backlog: no deadline, no batch, no short-term expectation.

Rules:
- One `.md` file per parked idea (same format as a `TODO/` file:
  description + actions as `- [ ]` boxes).
- A task goes to ICEBOX from `TODO/` (explicit deprioritization decision)
  or is born here directly if the idea is not yet mature.
- To reactivate it: move the file to `TODO/` (then follow the normal
  lifecycle). Never start a task directly from ICEBOX without going back
  through `TODO/` — otherwise it escapes batching.
- Does not count in the `CLAUDE_BATCH.md` checks (the `crew_hook.py` hook
  only watches `TODO/`/`CURRENT_TASKS/`).
- `INDEX.md` is regenerated by `crew/crew_hook.py` — do not edit it by hand.
