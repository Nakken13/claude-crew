Validation checklists for finished features, sorted by who runs them:

- `IA/` — tests the AI can run alone (🤖 auto pytest/scenario/front,
  🔍 direct config/query: curl, DB, logs, CLI).
- `DEV/` — tests that really need the dev (🖱️ manual/visual in the browser,
  real mobile, or an item the AI has no tooling for).

Same workstream → one file on each side (same name + title), only the
items differ. `INDEX.md` (root + per subfolder) is regenerated by
`crew/crew_hook.py` — do not edit it by hand.
